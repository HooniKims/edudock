공식 로그인

Edge에서 안전하게 로그인

업무 버튼을 누르면 일반 Edge에서 업무포털을 엽니다. 인증서 선택과 암호 입력은 공식 창에서 직접 진행하세요.

1저장된 비밀번호이 컴퓨터에 안전하게 보관 중이에요. 지우면 자동 로그인도 꺼지고, 인증서 창에서 직접 입력합니다.
1인증서 비밀번호 저장저장하면 자동 로그인이 함께 켜지고, 로그인할 때 인증서 비밀번호를 대신 입력해요. 이 컴퓨터의 지금 Windows 계정에서만 풀 수 있게 암호화해 보관합니다.

이 컴퓨터에서는 비밀번호를 안전하게 암호화할 수 없어 저장 기능을 쓸 수 없어요. 인증서 창에서 직접 입력해주세요.

위젯 위치

아래 그림에서 위젯을 붙일 모니터의 가장자리를 누르세요.

  • 끌어서 옮기기 위젯 바깥쪽의 점선 손잡이를 끌면 다른 모니터로도 옮길 수 있어요. 끄는 동안 붙을 자리가 파랗게 표시됩니다.
  • 오른쪽 클릭 위젯을 오른쪽 클릭하면 위치 메뉴가 바로 열려요.
