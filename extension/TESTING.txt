현재 단계: 자동 테스트 통과, 임시 Edge 프로필에서 설치 직후 설정 탭·강원 권한 창·팝업 확인.
서울 외 지역의 실제 로그인 화면에서 장시간 유지는 아직 검증 전입니다.
제출 상태는 Microsoft Edge 파트너 센터와 Chrome 웹 스토어 개발자 대시보드에서 확인합니다.

동작
- 필수 권한은 1.1.0과 같습니다(sen.eduptl.kr, klef.sen.go.kr). 나머지 49개 주소는 선택 권한이라
  업데이트해도 확장이 꺼지지 않습니다.
- 새로 설치하면 setup.html이 저절로 열립니다. 교육청을 고르고 [사용 허용하고 켜기]를 누르면
  그 교육청의 업무포털·K-에듀파인·나이스 접근을 요청하고, 허용하면 세션 유지를 켭니다.
- 1.1.0에서 업데이트하면 서울로 설정됩니다. 서울 나이스를 허용한 적이 없을 때만 설정 탭을 엽니다.
- 설정이 끝나지 않은 동안 확장 아이콘에 주황색 '!'가 붙습니다. 팝업에서 교육청을 바꿀 수 있습니다.
- 경북 K-에듀파인 주소는 klef.gbe.kr입니다(klef.gbe.go.kr은 DNS에 없음).
- '세션 유지'가 켜져 있으면 4분마다 기존 탭에서 실행합니다.
- 나이스 공식 /sessionExtension.do 응답이 정확히 "Y"인 경우만 기본 타이머를 갱신합니다.
- 시간만 60분으로 표시되는 것을 메뉴의 정상 동작으로 판단하지 않습니다.
- 로그인 정보가 없거나, 타이머가 종료됐거나, 화면에 오류 안내가 있으면 실행하지 않습니다.
- 시계 아이콘을 누르지 않으며 2차 인증 타이머를 초기화하지 않습니다.
- 인증 정보, 응답 본문, 오류 원문, 계정 정보는 로그에 저장하지 않습니다.

실제 Edge 확인 절차
1. edge://extensions 에서 압축 해제된 확장으로 이 폴더를 로드합니다.
   이미 이 폴더를 개발용으로 사용 중이면 해당 카드의 새로고침을 누릅니다.
   기존 스토어 확장과 동시 실행하지 않습니다. 데스크톱 자동 로그인 설정은 변경하지 않습니다.
2. 나이스에 정상 로그인한 상태에서 '나이스 접근 허용'에서 사이트 접근을 허용합니다.
3. '지금 연장'을 누릅니다. 최근 기록의 서버 응답과 실제 메뉴 동작을 각각 확인합니다.
4. 자동 실행 2회 이상과 기존 기본 세션 만료 시점을 지난 뒤에도 메뉴가 동작하는지 확인합니다.
5. 오류 안내가 있는 경우 '화면 오류 감지', 종료 상태인 경우 '세션 종료 감지'로 기록되고
   타이머가 새로 시작하지 않는지 확인합니다. 작성 중인 내용이 있으면 먼저 보존합니다.
6. 2차 인증의 시간은 별도로 흐르는지 확인합니다. 연장은 나이스 화면에서 직접 합니다.
7. 실제 오류 원인을 조사하려면 오류 문구, 발생 시각, 눌렀던 메뉴를 기록합니다.
   나이스 서버 내부의 프로그램 처리 로그는 이 확장으로 조회할 수 없습니다.
