# 업무포털 도우미 (EduDock)

화면 가장자리에 붙어 있는 작은 위젯에서 **나이스**와 **K-에듀파인**을 바로 여는 Windows용 업무 도우미입니다.
평소 쓰는 Microsoft Edge에서 서울교육 업무포털 로그인부터 원하는 업무 화면까지 이동합니다.

> 개인이 만든 **비공식 도구**이며 교육부·서울특별시교육청과 관련이 없습니다. 나이스·K-에듀파인은 각 기관의 서비스 이름입니다.

## 내려받기

[최신 릴리즈](../../releases/latest)에서 둘 중 하나를 받으세요.

| 파일 | 설명 |
| --- | --- |
| `EduDock-Setup-x.y.z.exe` | **설치형(권장).** 새 버전이 나오면 자동으로 내려받고, 재시작하면 설치됩니다. |
| `EduDock-Portable-x.y.z.exe` | 설치 없이 바로 실행합니다. 새 버전이 나오면 알려 주며, 새 exe를 직접 내려받아 바꿔야 합니다. |

> 코드 서명이 없는 프로그램이라 처음 실행할 때 Windows가 **"PC 보호"** 창을 띄울 수 있습니다.
> **추가 정보 → 실행**을 누르면 됩니다. 받은 파일이 원본인지는 릴리즈의 `SHA256SUMS.txt`로 확인할 수 있습니다.
>
> ```powershell
> Get-FileHash .\EduDock-Setup-x.y.z.exe -Algorithm SHA256
> ```

## 할 수 있는 일

- **나이스 · K-에듀파인 · 개인근무상황 · 출장 · 일반기안문** 버튼 하나로 해당 화면까지 이동
- 인증서 로그인: 하드디스크의 인증서를 먼저 찾고, 없으면 이동식 저장매체를 차례로 확인
- **인증서 비밀번호 저장(선택):** Windows 계정 암호화(DPAPI)로 이 PC에만 보관하며, 저장하면 시작할 때 자동 로그인이 켜집니다
- **초안 만들기:** 일반기안·출장·근무상황 문구를 정리하고, 일반기안은 새 기안창에 제목과 본문을 바로 넣기
- 위젯 위치: 설정의 모니터 그림에서 가장자리를 누르거나, 위젯을 오른쪽 클릭하거나, 손잡이를 끌어서 이동(듀얼 모니터 지원)

## 지키는 원칙

- **신청 · 상신 · 발송은 절대 자동으로 누르지 않습니다.** 화면까지 데려다줄 뿐 결정은 사용자가 합니다.
- 인증서 비밀번호는 설정 파일 · 로그 · 보고서 어디에도 평문으로 남기지 않습니다. 암호화를 쓸 수 없는 PC에서는 저장 자체를 거부합니다.
- 비밀번호가 틀리면 저장된 값을 지우고 다시 시도하지 않습니다(반복 시도로 인증서가 잠기지 않도록).
- 별도의 자동화 브라우저 프로필을 만들지 않고, 평소 쓰는 Edge를 그대로 씁니다.
- 초안 내용은 외부 서비스로 보내지 않습니다. 업데이트 확인을 위해 GitHub에만 접속합니다.

## 요구 사항

- Windows 10/11 (x64)
- Microsoft Edge
- 업무포털 인증서 프로그램(KCase) — 업무포털 로그인 화면의 안내에 따라 설치

## 개발

```powershell
npm install
npm test          # 단위·회귀 테스트
npm start         # 개발 실행 (업데이트 확인은 꺼짐)
npm run build     # release/<버전>/ 에 설치형·포터블·latest.yml·SHA256SUMS.txt 생성
npm run release   # 테스트 → 빌드 → GitHub 릴리즈 게시 (gh 로그인 필요)
```

- `src/` — 메인 프로세스(위젯 창, 트레이, 설정, 업데이트, Edge·기안창 연동)
- `src/native/` — 마우스를 움직이지 않고 화면을 읽고 누르는 PowerShell/UIA 도우미
- `renderer/` — 위젯과 설정·초안 화면
- `tests/` — `node --test` 테스트
- `scripts/` — 실제 설치본을 띄워 누르는 QA 스크립트

릴리즈 절차는 [RELEASING.md](RELEASING.md)를 보세요.
